## About

Jaribu Tech Solutions is a Kenyan software development agency building custom digital products for businesses and startups across Africa. We work across the full stack — from product design and web development to cloud infrastructure and IT consulting.

---

## Services

- Web Development — custom websites and web applications built to production standards
- Mobile App Development — cross-platform mobile solutions
- IT Consulting — technology strategy and systems advisory
- Cloud Solutions — deployment, infrastructure, and cloud architecture
- Cybersecurity — security audits, hardening, and best practices
- Technical Support — ongoing maintenance and support contracts
